🎉🎉**FINANCE TRACKER**🎉🎉

​A lightweight, cross-platform, console-based financial management utility written in Python. 

Finance Tracker allows users to effortlessly create savings plans, record monetary contributions, track balances, and audit overall fiscal health—all while persisting data locally via JSON serialization.

`**Features:**`

**Create Plan:** Initialize a new savings goal by specifying a unique plan name, a purpose (constrained between 0 and 15 characters), and an initial monetary contribution.

**Record Amount:** Dynamically view an ordered list of active plans, select a preferred goal, and append new monetary values with automatic timestamping.

**Track Record:** Inspect specific financial metrics, purposes, and current totals for a chosen plan.

**Total Amount Recorded:** Output a comprehensive ledger detailing all established plans, their purposes, accumulated balances, and the last recorded timestamps.

**Quit:** Gracefully terminate the execution loop.

`**Other Amazing Features:**`

-Works entirely offline! Once you get an active internet connection, you just synchronize it with your google account you used to log in and it stores in your Google Drive (but hidden)

-Utilizes SHA-256 Password Encryption Algorithm to ultimately lock data and reveal it to you only when the password matches.
